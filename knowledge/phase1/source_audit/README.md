# Source selection audit

The files in `not_selected/` are retained only for provenance. They are not
referenced by `extraction-report.json` or any pending/approved dataset.

- `constitution-34f9537ee5df-santhal-english-diglot.pdf` was excluded after
  inspection showed that it is the Santhali (Ol Chiki)–English diglot edition,
  rather than the intended English extraction source.
- `bns-ff92dcc72778-prior-indiacode-copy.pdf` is an earlier official India Code
  download. It was set aside so Phase 1 has one pinned BNS source: the official
  Gazette copy linked from the Delhi Police/MHA new criminal laws page. This
  audit entry does not say that the India Code copy is legally invalid.

Neither file may be approved or imported through the Phase 1 review process.
